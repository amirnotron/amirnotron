### 👨‍💻 About Me

Welcome to my digital workspace! I'm **Amir**, a full-stack developer dedicated to building high-performance web applications and scalable backend systems. My core expertise lies within the modern **JavaScript/TypeScript ecosystem**, where I focus on crafting elegant solutions from the server to the user interface.

* 🔭 Currently building my multi-functional portfolio at [notron.top](https://notron.top) and continuously scaling a verified, high-traffic Discord bot.
* 💻 **Primary Focus:** Building server-rendered frontend architectures with **Next.js** & **React**, and creating powerful backends using **Node.js** & **Express.js**.
* 🌱 Constantly exploring advanced routing, full-stack optimization, and modern UI design using Tailwind CSS.
* ⚡ **Fun fact:** It all started with `console.log("Hello world!");`
